# terminal-sky

今夜の星空をターミナルに描く Go の CLI。星座線・惑星・月齢・今夜の見どころ

## これは何
sky now を打つと、選んだ都市から今夜見える星空 (星・星座線・惑星・月) と見どころが端末に出て、画面と実際の空を見比べて星を探せる

## インストール
[Releases]((まだ公開していません)) から、自分の OS のファイルを取ってくる。または:

```bash
go install github.com/Rin0107/terminal-sky/cmd/app@latest
```

## 使い方
```bash
alias sky=terminal-sky                          # 短く打てるように (任意)
sky now                                         # 東京の今の空
sky now --at 2026-01-15T21:00:00+09:00          # 時刻を決めて (RFC 3339)
sky now --city tokyo --width 60 --height 20     # 都市と描く大きさ (既定 80×24)
sky now --no-lines                              # 星座線を消す (星座の名前と星の点は残る)
```
空を真上から見た図で、中心が天頂、縁の点が地平線。上が北・左が東・下が南・右が西
(寝ころんで南に頭を向けずに見上げた向き)。明るい星ほど目立つ文字で描く: `●` (0.5 等より明るい) > `*` (1.5 等まで) > `+`。
星座は 13 個 (オリオン・おおいぬ・こいぬ・ふたご・おうし・ぎょしゃ・カシオペヤ・おおぐま・はくちょう・こと・わし・さそり・しし)。
線は `-` `|` `/` `\` で描き、名前は「オリオン座」のように「座」まで書いて星の名前と見分ける。

## 星の目録の出典
2 等級より明るい恒星 48 個と、星座線を結ぶための暗い星 54 個の J2000.0 の位置と V 等級は、
Yale Bright Star Catalogue 第 5 版 (Hoffleit & Warren 1991、公開の星表) から。
恒星時・歳差・地平座標の計算は Meeus『天文アルゴリズム』(12・13・21 章) の式による。
